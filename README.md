# Portfólio de Analista de Dados — Euller Fernando

Este repositório reúne meu portfólio profissional como Analista de Dados, com foco em transformar dados em informações claras para apoiar decisões de negócio.

O site apresenta uma seleção de projetos, exemplos de dashboards e indicadores, além das ferramentas que utilizo no processo de análise — da preparação dos dados à comunicação dos resultados.

## Sobre o portfólio

Meu objetivo é demonstrar como utilizo análise de dados para responder perguntas de negócio, identificar oportunidades e acompanhar indicadores importantes. Cada projeto foi estruturado para evidenciar contexto, abordagem analítica, ferramentas utilizadas e impacto esperado.

## Conteúdos apresentados

- Dashboard executivo de receita com indicadores de faturamento, metas, ticket médio e novos clientes;
- Análise de retenção de clientes, com foco em coortes e pontos de abandono;
- Projeto de previsão de demanda para apoiar o planejamento de estoque;
- Resumo das experiências, competências e tecnologias utilizadas.

## Tecnologias e ferramentas
